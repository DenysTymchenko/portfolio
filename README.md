# Portfolio — a cozy 3D room

A developer portfolio you walk through as a red panda: a room with a desk (about me), a vinyl
cabinet (projects) and an apple garden (work experience). Everything lives in the 3D world —
no HTML panels.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

**Controls:** WASD / arrows to walk, Shift to run, Space to jump, E to interact, scroll to zoom,
click the floor to walk there. On touch screens: drag to walk, tap to interact, pinch to zoom.

- **Desk:** sit down (E, or click the laptop) and the camera moves onto the laptop screen.
- **Vinyl cabinet:** click a record (or E nearby) — it plays and the cork board shows the project.
- **Garden:** bump into a tree (or E nearby) to shake an apple loose — the noticeboard shows the job.

## Project structure

One component per file, named after the thing it represents, grouped by feature.

```
src/
  main.tsx, App.tsx     entry + app shell (canvas, drag joystick, hidden HTML copy of the content)
  styles.css            page + laptop-screen styles
  data/                 your content (profile, projects, experience)
  hooks/                useDiorama: named objects from diorama.glb
  state/                appState (zone, seated, selected project / job), pandaState (per-frame position)
  utils/                input, fonts, materials, colors
  scene/
    Scene.tsx           puts the world together
    Diorama.tsx         the Blender model, its collider, click-to-walk
    Lights.tsx  Effects.tsx  FollowCamera.tsx
    panda/              Panda — the red panda you control
    sky/                Sky (sunset gradient) + Cloud
    zones/              Zones → one Zone per point of interest (+ its floor ring), ZonePrompt bubble
    room/               Room → NameWall, CardboardBox, controls painted on the floor
    desk/               Laptop → LaptopPage (the real web page on the screen)
    vinyl/              VinylCorner → RecordSleeve, PlayingRecord, ProjectBoard
    garden/             Garden → AppleTree → Apple, JobBoard, BeachBall, Fireflies
    shared/             Anchored, TextColumn, TextLink, FloorText
blender/scripts/        Python that builds the 3D models in Blender
public/models/          exported diorama.glb + panda.glb
```

Conventions: object shapes are `interface`s prefixed with `I`, named after the data
(`experience` → `IExperience`, component props → `IRecordSleeveProps`); `type` is only used for
unions such as `ZoneId`, which an interface can't express.

## How it's built

- **3D models are generated by code.** `blender/scripts/build_diorama.py` and `build_panda.py`
  build everything from primitives (helpers in `toybox.py`); `export.py` rebuilds both, writes
  `public/models/diorama.glb` and `panda.glb`, and saves `blender/diorama.blend`.
- **One visual style: faceted low-poly toys.** The rules live in `blender/scripts/toybox.py`
  (chamfered blocks, 6-12-sided round things, jittered blobs for foliage and rocks, matte flat
  colors) and `src/utils/materials.ts` (every loaded material forced matte + flat-shaded).
  Lighting is a summer evening (`Lights.tsx`): low warm sun against a cool lavender fill, a
  sunset sky and clouds (`sky/`), lamps and fairy lights on, fireflies, bloom only on light
  sources (`Effects.tsx`), and neutral tone mapping so colors stay as designed.
- **Named objects drive the app.** The diorama carries named empties — `Spot_*` (spawn, desk,
  chair), `Zone_*` (zone centres), `Anchor_*` (where text, the laptop screen and records go),
  `Light_*` (lamps) — read through `src/hooks/useDiorama.ts`, so moving furniture in Blender
  doesn't need code changes. Apple trees work the same way: every `Tree_N_Canopy` in the model
  becomes an `AppleTree`, so adding a tree in `build_diorama.py` (`APPLE_TREES`) is all it takes.
- **Physics (Rapier):** the diorama is one static trimesh collider; the panda is a kinematic
  character controller (`panda/Panda.tsx`) that pushes the ball, boxes and fallen apples around.
- **The panda is rigid parts**, each pivoting at its joint, animated procedurally in `Panda.tsx`.
- All content is also rendered as hidden HTML for screen readers and search engines (`App.tsx`).

`reference/` holds the mood images and the panda concept.
