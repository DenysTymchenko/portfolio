# Portfolio — a cozy 3D room

A developer portfolio as a diorama: a room with a desk (about me), a vinyl cabinet (projects)
and an apple garden (work experience), with a red panda walking around.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

## Your content

| File | Shows up as |
| --- | --- |
| `src/content/profile.ts` | the laptop screen: name, summary, tech stack, contacts |
| `src/content/projects.ts` | records in the cabinet (first 8) + the Projects panel |
| `src/content/experience.ts` | apples on the trees + the Experience panel |

## How it's built

- **3D models are generated by code.** `blender/scripts/build_room.py` and `build_panda.py` build
  everything from primitives (helpers in `toybox.py`); `export.py` rebuilds both and writes
  `public/models/room.glb` and `panda.glb`. `blender/room.blend` is the saved result.
- **Named markers drive the app.** Empties in `room.glb` — `Spot_*` (panda waypoints),
  `Focus_*` (camera targets), `Anchor_*` (laptop screen, cubbies, platter), `Light_*` — are read
  in `src/components/useRoom.ts`, so moving furniture in Blender doesn't need code changes.
- **The panda is rigid parts**, each pivoting at its joint; `src/components/Panda.tsx` walks it
  between spots and animates legs, arms, head and tail procedurally.
- React Three Fiber + drei; camera framing in `CameraRig.tsx`, HTML panels in `Overlay.tsx`.

`reference/` holds the mood images and the panda concept.
